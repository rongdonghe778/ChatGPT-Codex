# C 语言贪吃蛇

这是一个在终端中运行的简易贪吃蛇示例，使用 ANSI 转义序列进行绘制，
使用 `termios` + 非阻塞读取捕获键盘输入。无需额外依赖库。

## 功能说明

- 方向控制：支持方向键或 WASD。
- 随机食物：吃到食物后长度增加并计分。
- 碰撞检测：撞墙或咬到自己时结束。
- 重开/退出：Game Over 后可按 `R` 重开或 `Q` 退出。

## 编译与运行

在仓库根目录执行：

```bash
gcc -Wall -Wextra -o snake src/snake.c
./snake
```

> 如果你在 macOS 上编译，需要确保 `gcc` 指向 clang 或已安装的 gcc。

## 操作方法

- **方向键**：上 / 下 / 左 / 右
- **WASD**：W 上、S 下、A 左、D 右
- **R**：游戏结束后重开
- **Q**：退出游戏

## 文件结构

```
src/snake.c        # 游戏源码
docs/SNAKE_README.md  # 详细说明文档
```

## 运行原理简述

1. **终端模式切换**：通过 `termios` 关闭行缓冲与回显，实现实时按键响应。
2. **游戏循环**：固定时间步（tick）更新蛇的位置与状态。
3. **渲染**：使用 `\033[H` 将光标移到左上角，逐帧重绘边界与蛇身。
4. **输入处理**：`select` + 非阻塞 `read`，同时支持 WASD 与方向键序列。
